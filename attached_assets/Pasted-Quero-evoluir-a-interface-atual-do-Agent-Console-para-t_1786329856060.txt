==================================================
6. COMPORTAMENTO DO SHADOW MODE
==================================================

Quando:

shadow_mode = true

o sistema deve continuar monitorando normalmente o Jira.

PERMITIDO:

- consultar Jira;
- detectar cards;
- executar ticks;
- identificar cards elegíveis;
- atualizar observabilidade;
- enviar eventos ao console;
- registrar o que seria executado;
- mostrar "would trigger" no execution log.

Exemplo:

[shadow] would trigger SSAI-88

Porém NÃO pode executar nenhum efeito colateral.

PROIBIDO em Shadow Mode:

- criar thread de execução;
- executar dispatch_agent_run;
- iniciar agent graph;
- chamar LLM;
- mover card Jira;
- comentar no Jira como parte de uma execução;
- criar branch;
- fazer commit;
- fazer push;
- alterar GitHub;
- criar Pull Request;
- modificar Pull Request;
- executar implementação;
- executar reviewer;
- retomar execução real;
- realizar qualquer ação do workflow.

Ou seja:

Shadow Mode ON
=
monitoramento somente.

Shadow Mode OFF
=
execução real habilitada.

A garantia de segurança deve existir no BACKEND.

Ela não pode depender do botão do frontend.
